# Balaji Pawn Broker — Desktop Releases

This repo holds only compiled desktop installer releases (and their update
metadata) for the Balaji Pawn Broker desktop app, published automatically by
CI from the private source repo. There is no source code here — see
[balaji-pawn-broker](https://github.com/Anshul-Sharma-1215114/balaji-pawn-broker)
(private) for that.

Existing installs auto-update from the releases published here via
`electron-updater` — nothing to do manually.
